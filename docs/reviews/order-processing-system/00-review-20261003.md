### CIO — Operations, Security & Compliance

- **R3 — RISK:** successful admin mutations have no actor/action audit record or request correlation ID.
  - Evidence: [product creation](/Users/amritraj/Downloads/projects/order_management/api/rest/v1/product_handler.go:40), [status updates](/Users/amritraj/Downloads/projects/order_management/api/rest/v1/order_handler.go:148), [middleware](/Users/amritraj/Downloads/projects/order_management/api/rest/server.go:41).   - Evidence: [login branches](/Users/amritraj/Downloads/projects/order_management/service/auth/jwt/client.go:63), [password verification](/Users/amritraj/Downloads/projects/order_management/domain/user/user.go:41).

- **R5 — RISK:** public registration/login have no attempt throttling, permitting unrestricted credential attempts and repeated expensive password work.
  - Evidence: [public auth routes](/Users/amritraj/Downloads/projects/order_management/api/rest/routes/routes.go:34), [registration hashing](/Users/amritraj/Downloads/projects/order_management/service/auth/jwt/client.go:48), [middleware](/Users/amritraj/Downloads/projects/order_management/api/rest/server.go:41).
  - Action / owner: Auth owner adds configurable auth-route throttling with tested 429 responses and documents process-local versus ingress enforcement. This does not require Redis or a new identity provider.
