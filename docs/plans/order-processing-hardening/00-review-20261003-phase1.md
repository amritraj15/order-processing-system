# Scope review

The [overview](01-overview.md) and [engineering design](02-engineering-doc.md)
resolve the following design questions.

- Region selects a target currency for a new quote. The catalog retains one base
  currency, and existing orders keep their original purchase snapshots.
- Currency mappings and exchange rates are separate. Managed rates have explicit
  validity periods; missing or expired rates reject conversion.
- Worker readiness distinguishes startup, failure, stale progress and recovery.
- Authentication limits bound both request volume and password-check concurrency.
- Transactional writes and conditional status changes protect retries and races.
- Local unit, PostgreSQL integration and Docker smoke tests cover different layers.

Live FX providers, payments, inventory, analytics services and a distributed
scheduler are outside the assignment scope. See the [test matrix](04-test-plan.md)
for local checks of the included behavior.
