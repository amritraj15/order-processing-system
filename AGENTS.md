## Project overview

Standalone order-processing assignment: create multi-item orders, retrieve/list
with optional status filtering, advance status, cancel only while PENDING, and
automatically move PENDING orders to PROCESSING every five minutes.
The accepted implementation also includes customer/admin authentication and an
admin-managed catalog whose database prices determine order totals. The approved extension adds managed-rate regional quotes while preserving one immutable base catalog currency and existing order snapshots.

## Stack and layout

- Go 1.26, Echo v5, GORM/PostgreSQL, golang-migrate, JWT HS256 and bcrypt.
- `domain/`: business types, invariants, repository interfaces; `service/`:

- `api/rest/`: HTTP handlers, middleware and route registration;
